# Конвертер MDB → DB

Программа для автоматической конвертации баз данных Microsoft Access из формата **`.mdb`** в формат **`.db` (SQLite)**.

Приложение позволяет быстро перенести структуру таблиц и содержащиеся в них данные из Access в SQLite, минимизируя необходимость ручной обработки базы данных.

## Возможности

* Конвертация баз данных **`.mdb → .db`**
* Автоматический перенос таблиц
* Перенос данных из исходной базы
* Сохранение структуры базы данных
* Простое управление процессом конвертации
* Быстрая обработка базы данных
* Работа с локальными файлами

## Как это работает

1. Пользователь выбирает исходный файл **`.mdb`**.
2. Программа подключается к базе Microsoft Access.
3. Получает список таблиц и их структуру.
4. Создаёт новую базу данных **SQLite `.db`**.
5. Переносит таблицы и содержащиеся в них данные.
6. Сохраняет готовую базу в указанном месте.

## Требования

* Windows
* Python 3.10+
* Установленный драйвер **Microsoft Access ODBC**
* Доступ к исходному `.mdb` файлу

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его:

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Запустите программу:

```bash
python main.py
```

После запуска выберите `.mdb` файл и укажите место для сохранения результирующей базы `.db`.

## Пример

**Исходный файл:**

```text
database.mdb
```

**Результат:**

```text
database.db
```

При этом таблицы и данные из исходной базы переносятся в SQLite-базу.

## Назначение проекта

Проект предназначен для упрощения миграции старых баз данных Microsoft Access в более современный и удобный для программной обработки формат SQLite.

Конвертер может быть полезен при переносе данных из устаревших приложений, автоматизации обработки баз данных и разработке новых программ на основе существующих `.mdb` баз.
